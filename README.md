### ⚙️ The factory - an operating model for AI-native delivery

- **[keel](https://github.com/ckhamitkar/keel)** - an agentic SDLC harness: role-based agents (architect, dev-lead, QA, security, design, release) move work from intent to release through mutual-check gates and an **80% test-coverage hard gate**, on Claude Code + MCP. *The installable substrate of an engineering org - a new engineer, or an agent, operates at senior level within hours.*
- **[agentic-prd-factory](https://github.com/ckhamitkar/agentic-prd-factory)** - a **13-agent LangGraph pipeline** that pressure-tests a one-page intent across every product lens into a validated spec, through adversarial multi-round critique and a human-in-the-loop gate. A sanitized release of the factory I run at Axion.
- **[agent-law](https://github.com/ckhamitkar/agent-law)** - a governance framework for synthetic actors: **govern the ephemeral through the persistent** - the agent is gone in seconds, its provenance isn't, so accountability lives at the lineage. Deterministic floor + human-in-the-loop escalation, tamper-evident audit, threat-modeled against MITRE ATLAS.
- **[agentic-iam](https://github.com/ckhamitkar/agentic-iam)** - the deterministic control plane underneath: **authentication, authorization, and accounting for hierarchies of AI agents, with no LLM in the enforcement path.** ed25519 attestation + proof-of-possession, capability tokens with attenuating delegation, authority bound to provenance and budgets. A stolen token is useless; an agent reasoning on poisoned data still cannot exceed what it was delegated. The enterprise IAM problem, now for agents. MIT.
